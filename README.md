# FrameKit - Create robust and easy to use installers for custom Steam Frame applications

FrameKit allows you to package your custom Steam Frame ARM application with an installer that gives both Windows and Linux users an easy to use GUI application that makes installation as simple as with any common software.

## Features

- **No sideloading needed:** Quickly and easily package your existing applications in a self-installing setup, no sideloaders needed
- **Easy install:** The GUI guides users through setting up developer mode and pairing
- **Device detection:** Automatically detects Steam Frames in the network, including support for multiple connected devices
- **Fast:** Installation takes users only 3 clicks and less than 30 seconds
- **The Community App tab:** Also includes a Community Apps tab, letting you make commonly used commands from your tools available via user-facing GUI with a sleek style matching SteamVR's look. And the best part: the tab will show all applications installed via FrameKit in one convenient overview
- **Easy updates:** Supports one-click updates for your applications, both via PC or directly in the headset (same for uninstallation), including automatic update checks
- **Flexible:** Can install applications, CLI tools, services and SteamVR drivers and support install scripts (however, please note that only native ARM64 Linux applications are supported)
- **Secure:** Supports signed update packages to prevent toolchain attacks
- **Bonus:** Includes a custom C++ library for commonly used tooling (like JSON handling, bluetooth, timers, etc.) (still somewhat WIP)
